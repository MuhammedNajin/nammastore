# NammaStore

Manage your local shop via WhatsApp Voice & Vision. Built for Tier-2 & Tier-3 MSMEs.

## Features
- **Voice-to-Stock**: Speak naturally in regional languages to log sales and update inventory instantly.
- **Auto-Cataloging**: Snap a photo of new stock; AI vision generates product listings and storefront links.
- **AI Customer Concierge**: Automated WhatsApp replies handle customer pricing and availability queries 24/7.

## Getting Started

First, install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3001](http://localhost:3001) in your browser.
